#  EventQueue – Mini Eventbrite Clone (Frontend)

EventQueue is a **frontend-only event management platform** inspired by Eventbrite. It allows users to browse upcoming events, view detailed event information, and register (RSVP) for events through a simple and intuitive user interface.

This project was developed as part of a frontend challenge, focusing on **core functionality, clean UI, and basic interactivity** using only **HTML, CSS, and JavaScript**.

##  Project Overview

EventQueue simulates a real-world event discovery and registration platform. The goal is to create a functional prototype where users can:
- Explore multiple upcoming events
- View detailed event information
- Register for events with a dynamic attendee count

The scope is intentionally kept frontend-focused and achievable within **2–3 hours**, making it ideal for hackathons and learning-based projects.

---

##  Core Features

### 1. Event Listing Page
- Displays multiple upcoming events in a grid/list layout
- Each event card includes:
  - Event title
  - Date and venue
  - Short description or poster image

### 2. Event Detail Page
- Click on an event to view expanded details
- Shows:
  - Full description
  - Event time
  - Location information

### 3. RSVP / Register Functionality
- One-click “Join” or “Register” button
- Attendee count updates dynamically when a user registers

### 4. Navigation
- Simple and intuitive navigation between:
  - Event listing page
  - Individual event detail pages
